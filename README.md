# 鏡紙進行式 ｜ 數位策展門戶
### Mirror · Paper · In Progress — 元智大學中國語文學系 112 級實務製作成果展

元智大學中國語文學系 112 級實務製作成果展數位策展門戶。以「紙載古今、明鏡映心、動靜進行式」為核心理念，集結 12 組跨域數位人文展演，打破紙本閱讀界線，融合 AI 技術、互動敘事、桌遊策略、數位繪本與文創商品。

---

## 🌟 策展特色
- **純靜態 SPA 架構**：零外部建置工具依賴，現代語意化 HTML5 + CSS3 + 原生 JavaScript。
- **12 件展品黃金比例排版**：自適應 CSS Grid（桌面 3–4 欄、平板 2 欄、手機 1 欄），無縫對齊無分頁。
- **決定性視覺演算法 (Deterministic Identity Hashing)**：透過字串雜湊（DJB2 Hash）由展品標題自動運算生成專屬色彩相角、網格漸變與幾何浮水印。
- **防禦性安全強化**：嚴格白名單 URL Scheme 校驗（僅接受 `http://` 與 `https://`）、原生 DOM 安全節點建置阻絕 XSS。
- **環境自適應雙軌載入**：在線上主機模式下自動異步載入 `exhibits.json`；本機直接雙擊開啟時無縫切換備援資料層。
- **豐富互動體驗**：即時搜尋過濾、動態計數徽章、隨機探索聚光燈平滑滾動（Surprise Me）。

## 📂 檔案目錄架構
```
├── index.html        # 展廳總覽首頁、搜尋與 12 組展件網格
├── exhibit.html      # 專屬展件詳情二級頁（100-200字導讀、圖錄典藏、外網連結、相鄰展件切換）
├── style.css         # 鏡紙美學、文人方格稿箋、古典青海波水紋與自適應響應式斷點
├── app.js            # 首頁邏輯：搜尋、聚光燈、卡片動態導航
├── exhibit.js        # 詳情頁邏輯：展件載入、圖錄呈現、雙向導航
├── exhibits.json     # 12 項成果展品完整資料集（ID、標題、導覽文、圖錄路徑、展站網址）
├── exhibits-data.js  # 本地 file:/// 與雙軌相容展覽資料集
├── assets/images/    # 12 組展件專屬視覺圖錄典藏（SVG 向量美學畫卷）
└── README.md         # 專案說明文件
```

## 🚀 本地開發與預覽

### 方法 A：直接雙擊開啟
直接於檔案總管雙擊點開 `index.html` 即可在任何主流瀏覽器中順暢預覽。

### 方法 B：啟動靜態伺服器
```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```
前往瀏覽器開啟 `http://localhost:8000` 即可預覽。
